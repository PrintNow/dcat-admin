# 主题与侧边栏样式

> 后台外观由两个正交的开关决定：**主题**（`layout.color`，管整站配色）和**侧边栏样式**（`layout.sidebar_style`，管左侧栏）。

## 一、主题（`admin.layout.color`）

### 机制

1. `config('admin.layout.color')` 交给 `Color::getName()`；
2. `Asset::setUpTheme()` 把 `@adminlte` / `@dcat` 两个别名里的 CSS 文件名加上 `-{主题}` 后缀，例如 `navy` → 实际加载 `adminlte-navy.css` + `dcat-app-navy.css`；
3. 主题的 SCSS 变量入口有两个：
   - `resources/assets/dcat/sass/theme/_primary.scss` — 只放 `$primary`；
   - `resources/assets/dcat/sass/theme/_scheme.scss` — 放 `$primary` 之外的颜色。它在 `theme/_colors.scss` **末尾**被 `@import`，所以能覆盖 `_colors.scss` 里后面定义的 `$body-bg` / `$font-color`，又早于 AdminLTE `_variables.scss` 里的 `!default` 赋值（因此 `$sidebar-dark-bg` 也能覆盖）。
4. PHP 侧的色板在 `src/Color.php` 的 `$extensions`（供 `Admin::color()->all()` → 前端 `Dcat.config.colors` 使用）。

### 内置主题

| 名称 | 主色 | 页面底 | 文字色 | 深色侧边栏 | 浅中底 | 辅助色 |
| --- | --- | --- | --- | --- | --- | --- |
| `default` | #586cb1 | #eff1f7 | #414750 | — | — | — |
| `blue` | #6d8be6 | 同上 | 同上 | — | — | — |
| `blue-light` | #62a8ea | 同上 | 同上 | — | — | — |
| `green` | #4e9876 | 同上 | 同上 | — | — | — |
| `indigo` | #4f5fba | #f8f9fa | #1f2430 | — | #eff0ff | #8b8cf5 |
| `navy` | #2e68ff | #f2f5fa | （默认） | #0f1e3d | #e1e4e8 | #5b8cff |
| `emerald` | #0fa868 | #f4faf7 | #16342a | — | #e7f6ec | #3ed04a |
| `amber` | #f26b1d | #fbf5f0 | #3a2a1e | — | #fdeee1 | #fba05c |
| `midnight` | #4cc9f0 | （默认） | （默认） | #16181d | — | — |

- 「浅中底」用于侧边栏菜单选中项底色（仅当主题设置了该色才生效，见 `_menu.scss` 里的 `@if $scheme-tint`）。
- 「辅助色」编译成 `.text-scheme-accent` / `.bg-scheme-accent` 两个工具类（`sass/_colors.scss`）。
- `navy` / `midnight` 是深色侧边栏方案：侧边栏颜色由主题的 `$sidebar-dark-bg` 提供，因此 **主题 + `sidebar_style = 'dark'`** 即得到设计稿里的深色侧边栏。
- `midnight` 只提供「青色主色 + 近黑侧边栏」，**页面底/文字色保持框架默认**：不要在主题里翻 `$body-bg` / `$font-color` ——
  组件底色（`.box`、`.card`、按钮等）是写死的浅色，翻了会出现「近白文字落在白色卡片上」的不可用界面。
- 想要**整站深色**（对应设计稿的方案 E）：用 dcat 的 dark mode —— 应用侧在该端配置里加 `'body_class' => ['dark-mode']`，
  配套的深色组件样式在 `resources/assets/dcat/sass/theme/_dark.scss`（会覆盖 `.box` / `.card` / 表格 / 输入框等）。

### 新增一套主题的步骤

1. `theme/_scheme.scss` 头部的注释里补一行色值备忘；
2. `src/Console/MinifyCommand.php`：`$colors` 加主色；如需页面底/文字色/深色侧边栏/浅中底/辅助色，在 `$schemes` 里加同名的键；
3. `src/Color.php` 的 `$extensions` 加色板（`primary` / `primary-darker` / `link`）。`primary-darker` 请取编译产物里 `darken($primary, 5%)` 的结果，保持 PHP 与样式一致；
4. 同步注释：`config/admin.php`、`src/Console/stubs/config.stub`、`tests/resources/config/admin.php`；
5. 构建并发布：
   ```bash
   # 在已安装本包的 Laravel 应用里
   php artisan admin:minify all     # 编译全部内置主题（会临时改写 webpack.mix.js 与 theme/_primary.scss，结束后自动还原）
   php artisan admin:publish --assets
   ```
   框架仓库本身没有 `artisan`，需要单独构建时可直接在仓库根目录按 `admin:minify` 的做法改 `webpack.mix.js` 的 `let theme`、写 `theme/_primary.scss` 与 `theme/_scheme.scss`，然后 `npm run prod`。
6. 构建产物 `resources/dist/` 需要提交。

### 两个坑

- `theme/_scheme.scss` 生成时**只写主题真正提供的变量**：`$body-bg` / `$font-color` / `$sidebar-dark-bg` 写成 `null` 会覆盖掉默认值（`$font-color` 没有 `!default`，会导致文字色声明直接消失）；`$scheme-tint` / `$scheme-accent` 是新增变量，必须始终声明，否则 `@if` 会报未定义变量。
- 老主题（default/blue/blue-light/green）不需要因为新增主题而重新编译，它们的 CSS 不变。

## 二、侧边栏样式（`admin.layout.sidebar_style`）

### 映射

`src/Layout/Content.php` 的 `SIDEBAR_STYLE_CLASSES` 是唯一的映射表：

| 取值 | 输出的 CSS 类 | 说明 |
| --- | --- | --- |
| `light` | `sidebar-light-primary` | 默认，白底 + 主题色选中态 |
| `primary` | `sidebar-primary` | 实色主题色底 + 白字 |
| `dark` | `sidebar-dark-white` | 深色底（底色来自主题的 `$sidebar-dark-bg`） |
| `indigo` / `navy` / `emerald` / `amber` / `midnight` | `sidebar-{同名}` | 实色侧边栏，色值固定，不随主题变化 |

- **未命中的取值会原样当作 CSS 类名输出**，所以也可以直接填自定义类名；但类名必须包含 `sidebar-light-` 或 `sidebar-dark-` 才会继承 AdminLTE 的家族基础样式（`[class*='sidebar-light-']` / `[class*='sidebar-dark-']`），否则等于没有样式。
- `dark` 有额外语义：`Admin::jsVariables()` 用 `sidebar_dark` 表示「切回浅色时不恢复浅色类」。
- `sidebar_light_style` 必须等于页面实际渲染出来的类（现在由 `Content::sidebarStyleClass()` 统一解析），否则切暗黑模式时会残留类名。

### 实色侧边栏的实现位置

- 源码：`resources/assets/dcat/extra/sidebar-solid.scss`（色值表 + mixin + `@each`）；
- 产物：`resources/dist/dcat/extra/sidebar-solid.css`，注册在 `src/Layout/Asset.php` 的 `$baseCss`（与主题无关，独立打包，避免重复进 9 份主题 CSS）。
